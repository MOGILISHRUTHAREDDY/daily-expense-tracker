# Daily Expense Tracker 💰

## Project Description
The **Daily Expense Tracker** is a streamlined, user-friendly web application designed to help individuals effortlessly track their daily expenses and manage personal budgets. It provides a simple dashboard where users can input their daily spending, categorize their expenses, and instantly view their total expenditures in a sleek, responsive interface.

This project was built to solve the common problem of overspending by giving users clear visibility into where their money goes. By keeping track of expenses, users can make better financial decisions and stay within their designated budgets.

## Features
- **Effortless Expense Logging**: Add new expenses with descriptions, categories, and custom dates.
- **Categorized Spending**: Organize expenses by type (e.g., Food, Transport, Utilities, Entertainment, etc.) for easier tracking.
- **Live Balance Tracking**: The dashboard instantly updates your total spending dynamically as you add or delete items.
- **Persistent Data Storage**: All your data is securely saved directly into a local SQLite database—meaning your expenses will never disappear when you close the browser.
- **Zero Configuration Backend**: Powered by an embedded SQLite file database, the backend requires absolutely no complicated server or MySQL setup to run.
- **Responsive Web Design**: Clean and modern styling that adapts gracefully varying screen sizes.

## Technologies Used
* **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3 
* **Backend**: Node.js, Express.js API
* **Database**: SQLite3 (Embedded database for hassle-free localized storage)

## Getting Started (Run Locally)

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/YourUsername/daily-expense-tracker.git
   ```
2. Navigate into the project folder:
   ```bash
   cd "Daily Expense Tracker"
   ```
3. Install the required Node packages (Express & SQLite3):
   ```bash
   npm install
   ```
4. Start the backend server:
   ```bash
   node server.js
   ```
5. Open your favorite web browser and navigate to:
   ```
   http://localhost:3000
   ```
